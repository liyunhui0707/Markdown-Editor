# Markdown 编辑器 · 交互外观原型

2026-11-04。设计候选，不是产品功能验收或发布版本。

直接在 Chrome 或 Safari 中打开 [index.html](index.html)，无需安装依赖、启动服务器或联网。

## 设计方向

一个安静、清晰、自然的 macOS Markdown 写作工具。正文始终是主角，界面在需要时提供帮助。

- 固定的空间分工：左侧找文档，中间写作，右侧看大纲；两侧均可收起。
- 统一排版：暖白纸面、低饱和绿色、细线图标；正文 17 px，舒适宽度 680 px，标题有明确层级。
- 控件各归其位：顶部放文档操作，第二行放格式与视图，底部放轻量状态和字数。
- 正常输入是正常状态：中文输入中只改变底部提示；真实失败才展示可理解的就地反馈。
- 覆盖完整场景：欢迎页、空白文档、长文、列表与表格、源码预览、搜索、设置、另存窗口、深色与专注状态。

名称 Markdown 与左上标识只是本轮设计占位，不代表重新命名产品。侧栏的收藏、归档等也是设计候选，不意味着已批准或实现对应产品能力。

## 建议体验顺序

1. 点击左侧几份示例，观察文章、清单、代码与表格的排版，点击右侧大纲。
2. 点击左上 Markdown 进入欢迎页，再新建一页；输入几句话，选中文字体验格式菜单。
3. 点击搜索或按 ⌘K；切换写作、阅读、源码预览。
4. 打开设置，切换浅色、深色、字体、字号、宽度，再进入专注模式；Esc 返回。
5. 打开另存窗口，体验取消和演示确认；底部“体验状态”可预览输入中与保存未完成。
6. 点击文档右上更多，预览收藏、创建副本、重命名与归档；“重置演示”恢复样例。

## 原型边界

全部文档都是内置合成样例。原型没有 Electron、IPC、文件选择或文件读写接口，没有账号、网络请求或持久存储；修改只留在当前页面内存中，刷新即重置。

“已备份”“已导出”、保存位置及归档都是模拟状态。内容编辑、格式工具和源码转换只用于体验，不是完整 Markdown 编辑或无损序列化实现，也不保证生产级 Undo、输入法或恢复语义。禁止用此页面处理唯一一份重要内容。

本原型没有更改正式应用的保存授权、原文件保护、权限策略或输入法控制。后续接入仍复用现有 Tiptap、Document Service 和状态模型；先确定外观，再逐项接入，不把这个演示编辑区变成第二套产品编辑器。
